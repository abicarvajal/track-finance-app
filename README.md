# track-finance-app - Personal Finance Tracker

A full-stack app to track your income and expenses.

## Tech Stack

- Angular (Frontend)
- Java Spring Boot (Backend)
- PostgreSQL (Database)
- Docker, GitHub Actions

## Features

- User authentication
- Add/Delete/View transactions
- Dashboard with graphs
- JWT-based security

## Getting Started

```bash
# Start Docker DB + backend
docker-compose up --build

# Frontend
cd frontend
npm install
ng serve
